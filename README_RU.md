# PICO 4 Motion Tracker Unlock (2.0.5)

Полная разблокировка приложения PICO Motion Tracker **2.0.5** для **PICO 4 (стандартная версия)** (A8110 / Phoenix, прошивка 5.13.x).
Приложение включается через **Magisk-модуль**: **обнаружение трекеров работает, установка / обновление / удаление полностью надёжны**. Системный раздел не изменяется — после удаления всё возвращается к заводскому состоянию.

> 📦 Скачать: [Releases](../../releases) → **v2.7** (единая сборка: стоковое планирование)
> 🔧 Требуется: Magisk 27+, PICO 4 стандартная версия

---

## 🆕 v2.7: единая сборка + перенос тюнинга

| Изменение | Детали |
|---|---|
| 🔀 **3 версии → 1 сборка** | Осталась одна сборка (стоковое планирование). При прошивке поверх старых Performance / EXTREME **автоматически восстанавливаются** заводские свойства |
| 🎛️ **Тюнинг перенесён** | Настройка CPU/GPU теперь в проекте **[pico4-power-mode](https://github.com/hhhbwc/pico4-power-mode)**: его Magisk-компаньон применяет её при активном режиме производительности и возвращает сток в остальных режимах |
| 🧹 **Чистое обновление** | Остатки свойств старых версий очищаются при обновлении (сразу + подстраховка при загрузке) |

> Зачем единая сборка? Поддерживать три сборки бессмысленно — разблокировка не зависит от планирования, а тюнинг теперь централизован в power-mode.

## 📥 Установка / Обновление / Удаление

### Установка
1. Убедитесь, что есть root (Magisk 27+)
2. Magisk → Модули → Установить из файла → выберите ZIP
3. Перезагрузка
4. Откройте приложение «Motion Tracker»

### Обновление (с любой старой версии, включая Performance/EXTREME)
Просто прошейте v2.7 поверх (**удалять не нужно**); привязки трекеров сохраняются, свойства старого тюнинга восстанавливаются.

### Удаление
Удалите модуль в Magisk → перезагрузка. Системный раздел не изменялся — заводская 2.0.4 возвращается сама.

| Сборка | Описание | Скачать |
|---|---|---|
| ✅ **v2.7 (единственная)** | Стоковое планирование; тюнинг — в pico4-power-mode | [`PICO4_MotionTracker_v2.7.zip`](../../releases/download/v2.7/PICO4_MotionTracker_v2.7.zip) |

## 🔧 Принцип работы

| # | Слой | Детали |
|---|---|---|
| 1 | Обход блокировок | priv-app overlay: **оригинальный APK 2.0.5** помещается в `/system/priv-app` (оригинальная подпись) |
| 2 | Права | Запуск как системное приложение — полные привилегии |
| 3 | **Нативный слой совместимости** | Символ `getSwiftTrackerInfoVector`, отсутствующий в прошивке P4, добавляется патчем системной библиотеки + крошечным форвард-шимом |
| 4 | **Жизненный цикл версий** | Автоматическая инвалидация кэша PackageManager в обе стороны |
| 5 | Гигиена свойств | Запись без сохранения; восстановление при удалении; с v2.7 — и при обновлении со старых версий |

## ❓ FAQ

**Q: Список трекеров пуст?**
Исправлено в v2.6. Если повторится — issue с `adb logcat | grep -E "Swift205Shim|devices:"`.

**Q: Куда делся тюнинг CPU/GPU?**
Перенесён в [pico4-power-mode](https://github.com/hhhbwc/pico4-power-mode). Применяется при включённом режиме производительности, иначе — сток.

**Q: Можно ли ещё прошить старые Performance/EXTREME?**
Старые релизы остались (v2.6), но не поддерживаются; v2.7+ — единая сборка. Для тюнинга используйте pico4-power-mode.

**Q: После OTA системы перестало работать?**
Ожидаемо — перепрошейте модуль и перезагрузитесь.
